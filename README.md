# notion-finance-data-pipeline
End-to-End Data Pipeline de finanzas personales. Automatiza la ingesta desde Notion (iOS Shortcuts) y la orquestación con Apache Airflow, procesando datos con Python (Pandas) para su almacenamiento en Snowflake Cloud Data Warehouse y visualización analítica en Power BI. Enfoque técnico enfocado a la toma de decisiones.
